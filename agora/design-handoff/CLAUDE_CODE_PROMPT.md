# פרומפט ל-Claude Code · פיתוח אפליקציית אגורה

> הדביקו את כל הקובץ הזה כהודעה הראשונה ב-Claude Code, מתוך תיקייה שמכילה את התיקייה `assets/` מהחבילה (gif, webp, fonts, svg).

---

## התפקיד שלך
אתה מפתח פרונטאנד בכיר. בנה את **אגורה** – לוח קהילתי למסירת חפצים בחינם ("לתת זה לקבל") – כאפליקציית ווב **מובייל-פירסט, RTL, בעברית**, שמרגישה כמו אפליקציה נייטיב. מקור האמת לעיצוב הוא מערכת העיצוב שבהמשך. אל תמציא סגנון חדש, אל תוסיף צבעים, צללים או אלמנטים שלא מופיעים כאן.

## סטאק
- React 18 + TypeScript + Vite
- Tailwind CSS עם הטוקנים שלמטה (ב-`tailwind.config.ts`), בלי ספריית UI חיצונית
- React Router, Zustand למצב, `lucide-react` לאייקונים
- PWA (manifest + service worker בסיסי), `dir="rtl"` ו-`lang="he"` על `<html>`
- נתוני דמו מקומיים (JSON) עם שכבת `api/` שקל להחליף בשרת אמיתי

## מערכת העיצוב (חובה, בדיוק כך)

### צבעים – 5 צבעים בלבד + אפור עזר אחד
| טוקן | ערך | שימוש |
|---|---|---|
| `ink` | `#1E1E1E` | כל הטקסטים, האייקונים והכפתורים הרגילים (רקע כהה, טקסט לבן) |
| `neon` | `#92FF5F` | לוגו, אווטאר, ו**רק** הפעולות שחייבות לבלוט: "אני בעניין", "פרסום בלוח", כפתור "למסור", תגית "חדש", לב שמור |
| `white` | `#FFFFFF` | רקע המסכים, כרטיסים, סרגל ניווט |
| `gray-100` | `#F6F6F6` | שדה חיפוש, משטחי תמונה, כפתורים משניים |
| `green-100` | `#CFFFB0` | תגיות (מצב החפץ, קטגוריה, שלבים) |
| `placeholder` | `#9C9E9C` | placeholder ולשוניות ניווט לא פעילות בלבד |

על כפתור `neon` הטקסט תמיד `ink`. אין גרדיאנטים.

### טיפוגרפיה – Gloria בלבד
- `assets/fonts/gloria-light-aaa.woff2` (300) ו-`gloria-demibold-aaa.woff2` (600), טעינה עם `@font-face` ו-`font-display: swap`. **יש רישיון שימוש.**
- סקאלה: לוגו 24 DemiBold · כותרת מקטע 24 Light · כותרת חפץ 20 DemiBold · גוף 14 Light (שורה 1.5) · משני 13 Light · ניווט 12 Light · כפתור 16 DemiBold.
- בלי טקסט גדול מ-24. כותרות מקטע ב-Light, לא Bold.

### מידות ורכיבים
- מסך בסיס 402 רוחב, שוליים צדדיים 24, גריד 2 עמודות עם רווח 16.
- **הדר:** לוגו (פינווהיל `neon` + "אגורה" 24 DemiBold) מימין, אווטאר עגול 40 `neon` משמאל. מתחת: שדה חיפוש 322×36, רדיוס 8, רקע `gray-100`, placeholder "מה תרצו לחפש היום?" 14 Light, אייקון מצלמה (חיפוש לפי תמונה) ופעמון לידו. **בגלילה ההדר מתכווץ לשורה אחת** (לוגו + חיפוש + פעמון), עם רקע לבן ו-`backdrop-blur` עדין.
- **משבצת חפץ:** תמונה 169×170, רדיוס 16, רקע `gray-100` בזמן טעינה. מתחת: שם (14 DemiBold), עיר·מרחק (13 Light, `ink` 60%), תגית מצב `green-100`. לב בפינה העליונה של התמונה. תגית "חדש" `neon` לחפץ שעלה בשעה האחרונה.
- **כרטיס:** רקע לבן, רדיוס 16, צל `0 2px 8px rgba(30,30,30,.12)`. שימוש מצומצם: כרטיס "על הפרויקט", כרטיסי מידע בדף חפץ, גיליונות.
- **סרגל ניווט תחתון:** לבן, גובה 75 + safe-area, צל `0 -2px 10px rgba(30,30,30,.08)`. חמש לשוניות: **ראשי · חיפוש · למסור · אהבתי · פרופיל**. אייקון 24 בקו 1.75 (2.25 בלשונית הפעילה), תווית 12 Light. פעיל = `ink`, השאר = `placeholder`. "למסור" הוא פעולה שפותחת את זרימת המסירה, לא לשונית.
- **כפתורים:** pill (רדיוס מלא), גובה 48 (קטן 40). ראשי `ink`/לבן, בולט `neon`/`ink`, משני `gray-100`/`ink`, קישור = טקסט עם קו תחתון.
- **צ'יפים:** גובה 40, רדיוס מלא, `gray-100`; נבחר = `ink` עם טקסט לבן.
- **גיליון (bottom sheet):** לבן, רדיוס עליון 28, ידית אחיזה, רקע מעומעם `rgba(30,30,30,.4)`.
- **אייקונים:** lucide-react בלבד, `strokeWidth={1.75}`, צבע `ink`. אייקונים מותאמים (google, stairs, heart-filled) נמצאים ב-`assets/icons/`.
- אזורי לחיצה לפחות 44×44. ניגודיות AA. פוקוס נראה לעין (טבעת `ink` 2px).

## מבנה ו-UX (לא לשנות)
- **מסך פתיחה** (`/welcome`, פעם אחת): האנימציה `welcome.webp`, הלוגו, "לתת זה לקבל", כפתור "התחברות עם גוגל" (`gray-100`, אייקון גוגל) וקישור "דילוג".
- **ראשי:** הדר → כרטיס "על הפרויקט" (כותרת "לתת זה לקבל", משפט אחד, 3 שלבים: מצלמים · מפרסמים · מוסרים, ואנימציית `hello.webp`) → מקטעים "באזור שלך" ו"עלו עכשיו" בגריד 2 עמודות או בגלילה אופקית.
- **חיפוש מתקדם:** 4 כרטיסי אקורדיון (מה מחפשים / איפה / מצב / סדר), סרגל תחתון "ניקוי הכל" + "הצגת N חפצים" (N מתעדכן חי).
- **תוצאות:** כפתור סינון עם מונה, צ'יפים מהירים, מעבר רשימה/גריד, "התראה על חדשים". אין תוצאות → `searching.webp` + "התראה על חדשים" + "ניקוי סינונים".
- **דף חפץ:** תמונה ביחס 4:3.4 עם כפתורים צפים (חזרה, שיתוף, לב), נתיב קטגוריה, כותרת, כרטיסי "מצב" ו"איסוף", תיאור, שורת המוסר, כללי מסירה בטוחה. סרגל דביק: "בחינם" + עיר איסוף מימין, **"אני בעניין"** (`neon`) משמאל.
- **פנייה למוסר (גיליון):** הודעה מוכנה, ביטויים מהירים, "ההודעה נשלחת בתוך האפליקציה. בלי שיחות בתשלום.", אימות טלפון חד-פעמי, ואז מסך "ההודעה נשלחה" עם `message-sent.webp`.
- **התחברות** רק כשפונים למוסר או מפרסמים: גיליון עם `verified.webp`, "המשך עם Google" / "המשך עם אימייל".
- **למסור – 4 שלבים** עם פס התקדמות: 1) תמונות + זיהוי אוטומטי ("נראה טוב, להמשך"), עם `add-photo.webp` במצב ריק; 2) פרטים (שם, קטגוריה, מצב: כמו חדש / מצב טוב / מעט פגום / לחומר גלם); 3) איסוף (יישוב עם "שינוי", גודל קטן/בינוני/גדול, זמנים בוקר/צהריים/ערב/בתיאום, מתג מדרגות); 4) סיכום + **"פרסום בלוח"** (`neon`) → מסך הצלחה עם `published.webp`.
- **אהבתי:** גריד שמורים; ריק → `saved-empty.webp` + "עוד לא שמרתם חפצים" + "לגלות חפצים".
- **פרופיל:** אווטאר, מונים (נמסרו / בלוח / אהבתי), לשוניות "בלוח" / "נמסרו", שורות תפריט; אורח → כרטיס התחברות.
- **הודעות:** תיבת שיחות ומסך שיחה עם בועות (`ink` לשלי, `gray-100` לשלהם).
- **קופי:** פנייה ברבים, פעלים בכפתורים, משפטים קצרים, "…" כתו אחד. שמור על כל הטקסטים כפי שהם כאן.

## הטמעת האנימציות
הקבצים ב-`assets/animations/` (WebP שקוף, מומלץ) וגיבוי ב-`assets/animations/gif/` (רקע לבן). כל לופ הוא 3 שניות: פעולה קצרה ואז מנוחה. **ההפסקה כבר מובנית בקובץ**, אל תוסיף לופ משלך.

| קובץ | מקום | גודל תצוגה |
|---|---|---|
| `welcome.webp` | מסך פתיחה | רוחב 260 |
| `hello.webp` | כרטיס "על הפרויקט" | 96 |
| `searching.webp` | אין תוצאות | 180 |
| `add-photo.webp` | למסור · שלב 1 ריק | 160 |
| `message-sent.webp` | ההודעה נשלחה | 190 |
| `published.webp` | החפץ פורסם | 190 |
| `saved-empty.webp` | אהבתי · ריק | 170 |
| `verified.webp` | גיליון התחברות | 130 |
| `community.webp` | פרופיל · כרטיס קהילה | רוחב מלא |
| `loading.webp` | טעינה (במקום ספינר) | 40 |

רכיב אחד לכל האנימציות:
```tsx
<Illustration name="searching" size={180} alt="" />
```
- `<picture>` עם `webp` ו-fallback ל-`gif`, `width`/`height` מפורשים כדי שלא יקפוץ, `loading="lazy"` חוץ ממסך הפתיחה, `alt=""` כשהאיור דקורטיבי.
- `prefers-reduced-motion: reduce` → הצג תמונה סטטית (`assets/illustrations/<name>.png`, הפריים הראשון).
- מתחת לאיור תמיד כותרת, משפט קצר ופעולה. אין איורים בדף הבית מלבד כרטיס "על הפרויקט", ואין בדף חפץ.
- אל תשנה צבע, תחתוך או תמתח את הקבצים, ואל תוסיף להם אלמנטים.

## קריטריונים לסיום
1. כל המסכים והזרימות שלמעלה עובדים מקצה לקצה עם נתוני דמו.
2. רק הצבעים והפונט מהטבלה; אין טקסט גדול מ-24; כל כפתור ≥ 44px.
3. ההדר מתכווץ בגלילה, הסרגל התחתון נשאר קבוע וכולל safe-area.
4. כל אנימציה מופיעה במקום שלה, נטענת בלי קפיצה, ומכבדת reduced-motion.
5. Lighthouse מובייל: Performance ≥ 90, Accessibility ≥ 95.
6. בדיקה ב-390×844 וב-360×780, RTL תקין בכל הרכיבים (חיצים, סדר, אייקוני חזרה פונים ימינה).

התחל בטוקנים וברכיבים, הצג לי את מסך הבית ואת דף החפץ, ורק אחר כך המשך לשאר הזרימות.
