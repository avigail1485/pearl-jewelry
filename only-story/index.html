  1. דבר אחד הכי גדול בכל מסךOne thing is biggest on every screenאם שני אלמנטים מתחרים על העין, אף אחד מהם לא מנצח. בחרו את המשפט שחייב להיקרא, ותנו לו פי שלושה מהגודל של כל השאר.If two elements compete for the eye, neither wins. Pick the line that must be read and give it three times the size of everything else.
  2. שלוש רמות, לא יותרThree levels, no moreכותרת, טקסט תומך ופעולה. כל רמה נוספת מרגישה כמו רעש. המספרים 1, 2, 3 בווידאו הם הסדר שבו העין קוראת.Headline, supporting text and an action. Every extra level reads as noise. The 1, 2, 3 in the video is the order the eye reads in.
  3. קרבה יוצרת קבוצהProximity makes groupsרווח קטן בין דברים שקשורים, ורווח גדול בין קבוצות. ככה הדף מסביר את עצמו בלי קווים ובלי מסגרות.Small gaps between related things, large gaps between groups. That's how a page explains itself without lines or boxes.
  4. צבע אחד לפעולהOne color for actionהשאירו את המבטא לכפתור. אם הוא מופיע בכל מקום, הוא כבר לא אומר "לחצו כאן".Save the accent for the button. If it appears everywhere, it no longer says "click here".

סדרו מחדש דף נחיתה של עסק קטן כך שהעין תעבור 1, 2, 3.Reorder a small business landing page so the eye moves 1, 2, 3.

פתחו את התרגיל בסטודיו, כתבו את המשפט החשוב ביותר של העסק, ובחרו תבנית. אחר כך העתיקו את הבריף ל־Claude Code כדי לבנות ממנו את הדף עצמו.Open the exercise in the studio, write the business's most important line, and choose a template. Then copy the brief for Claude Code to build the page itself.
