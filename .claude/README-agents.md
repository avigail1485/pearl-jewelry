# צוות הסוכנים של הסטודיו

| סוכן | כינוי | תפקיד |
|---|---|---|
| `logo-analyst` | הבלש | מנתח לוגו ומחלץ את ה-DNA שלו |
| `inspiration-scout` | הצייד | מחפש רפרנסים ומחלץ עקרונות |
| `logo-variations` | האלכימאי | מעצב וריאציות בפיגמה |
| `creative-director` | המנהל הקריאייטיבי | מבקר, נותן ציונים ובוחר כיוונים |

ופקודה אחת שמריצה את כולם לפי הסדר: **`/logo-lab`**

## התקנה ב-VS Code

**לשימוש בכל הפרויקטים (מומלץ):** העתיקי את התיקיות לתיקיית המשתמש שלך:

- `.claude/agents/*.md` ← אל `~/.claude/agents/`
- `.claude/skills/logo-lab/` ← אל `~/.claude/skills/logo-lab/`

ב-Windows: `C:\Users\<שם-המשתמש>\.claude\`
ב-Mac: `/Users/<שם-המשתמש>/.claude/`

**לשימוש רק בפרויקט הזה:** לא צריך לעשות כלום. הקבצים כבר בתיקיית `.claude` של הפרויקט.

אחרי ההעתקה פתחי שיחה חדשה ב-Claude Code, כדי שהסוכנים ייטענו.

## חיבור פיגמה

הסוכן `logo-variations` עובד דרך שרת ה-MCP של Figma. אם פיגמה עדיין לא מחוברת ל-Claude Code אצלך ב-VS Code, הריצי בטרמינל:

```
claude mcp add --transport http figma https://mcp.figma.com/mcp
```

אחר כך כתבי `/mcp` בחלון של Claude Code ואשרי את ההתחברות לחשבון הפיגמה.

## דוגמאות שימוש

```
/logo-lab
```

או ישירות מול סוכן מסוים:

```
תפעיל את logo-analyst על הלוגו בקישור הזה: <קישור פיגמה>
תפעיל את inspiration-scout – אני מחפשת השראות למותג תכשיטי פנינים יוקרתי ועדין
תפעיל את logo-variations – 6 וריאציות, לשמור על הפנינה, טיפוגרפיה יותר עכשווית
תפעיל את creative-director על הסבב האחרון
```

## איפה נשמרים התוצרים

```
logo-lab/<לקוח>/
  brief.md        – הבריף
  analysis.md     – ניתוח ו-DNA
  inspiration.md  – השראות
  variations.md   – טבלת וריאציות וקישורים לפיגמה
  review.md       – ביקורת והוראות לסבב הבא
```

## התאמה אישית

כל סוכן הוא קובץ טקסט רגיל. אפשר לפתוח אותו ולשנות:
- **`description`** – מתי Claude מפעיל את הסוכן מעצמו.
- **"מי אתה"** – האופי והקול של הסוכן.
- **"כללים"** – מה מותר ומה אסור.
