# Ad Marathon (3-in-1)

Run the triad **in sequence**; each stage consumes the previous output.

1. **Noam** (`noam-strategy`) – write `briefs/<slug>/01-strategy.md`.
2. **Dana** (`dana-creative`) – read 01, write `briefs/<slug>/02-creative.md`.
3. **Or** (`or-art-director`) – read 01 + 02, write `briefs/<slug>/03-art-direction.md` and layouts under `ads/<slug>/`.

## Rules
- Before Noam starts, confirm with the user: product/offer, audience, channels & formats, language(s), deadline. Proceed with stated assumptions if they say "go".
- Gate between stages: show a 5-line summary of each stage and let the user approve or redirect before the next one.
- Each stage ends with an explicit **Handoff** section; the next agent must quote it at the top of its own document.
- Tone throughout: professional, refined, goal-oriented.
- Final deliverable: a one-page summary — SMP, recommended concept, hero headline, key visual, file list.
