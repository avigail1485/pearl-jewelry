# 🎤 תמלול עברית — דיבור לטקסט

תוכנה מקומית פשוטה להכתבת עברית והפיכתה לטקסט, עם כפתור העתקה.
משתמשת במנוע הזיהוי המובנה של הדפדפן (Web Speech API) — **בלי מפתח API ובלי הרשמה**.

---

## הפעלה (Windows)

1. ודאי ש-[Node.js](https://nodejs.org) מותקן (גרסה 18 ומעלה).
2. לחיצה כפולה על **`הפעלה.bat`**.
3. הדפדפן ייפתח לבד בכתובת <http://localhost:3000>.

לחלופין, מתוך חלון טרמינל בתיקייה:

```
node server.js
```

> אם הפורט תפוס: `set PORT=3001 && node server.js`

## שימוש

| פעולה | איך |
|---|---|
| התחלה/עצירה של הקלטה | לחיצה על כפתור המיקרופון (או `Ctrl + M`) |
| העתקת הטקסט | כפתור **העתקה** (או `Ctrl + Shift + C`) |
| שמירה לקובץ | כפתור **הורדה כקובץ** (`.txt` בקידוד UTF-8) |
| עריכה ידנית | פשוט לכתוב בתוך תיבת הטקסט — גם תוך כדי הקלטה |
| פיסוק | כפתורי ההוספה המהירה (נקודה, פסיק, שאלה, שורה חדשה) |

בפעם הראשונה הדפדפן יבקש הרשאה למיקרופון — יש לאשר.
ההקלטה רציפה: גם אם יש שתיקה, התוכנה ממשיכה להאזין עד לחיצה על עצירה.

## העלאה לאוויר (אתר ציבורי)

התיקייה `public/` היא אתר סטטי לגמרי — אין צורך בשרת Node כשהיא באוויר.
מנוע הזיהוי דורש HTTPS, וכל האפשרויות הבאות מספקות אותו אוטומטית.

### הדרך המהירה — Netlify Drop (בלי חשבון, כ-30 שניות)

1. להיכנס ל-<https://app.netlify.com/drop>
2. לגרור לחלון את התיקייה **`public`** (את התיקייה עצמה, לא את הקבצים שבתוכה)
3. מתקבלת כתובת חיה מיד, למשל `https://שם-אקראי.netlify.app`

לשם קבוע יש ללחוץ **Site settings → Change site name** (דורש חשבון חינמי).

### GitHub Pages

מכיוון שבשורש המאגר כבר יושב `index.html` אחר, יש להגיש את האתר מתיקייה נפרדת:
ב-GitHub → **Settings → Pages**, לבחור ענף ותיקייה שמכילה את תוכן `public/`.

### Vercel / Cloudflare Pages

להצביע על תיקיית הפלט `public/` ולהשאיר את פקודת ה-Build ריקה.


## דרישות

- **דפדפן:** Google Chrome או Microsoft Edge במחשב (Firefox אינו תומך ב-Web Speech API).
- **אינטרנט:** נדרש חיבור — מנוע הזיהוי של הדפדפן מעבד את הקול בענן של הדפדפן.
- **Node.js:** רק כדי להגיש את הקבצים מקומית. אין שום תלות חיצונית (אין `npm install`).

## פרטיות

הטקסט נשאר אצלך במחשב — השרת רק מגיש קבצים ולא שומר או שולח דבר.
הקול עצמו נשלח לשירות הזיהוי של הדפדפן (Google/Microsoft), בדיוק כמו בכל אתר שמשתמש בהכתבה.
